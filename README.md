# Velaryn Code: downloads

Download the latest version from **[Releases](https://github.com/velaryn-soft/velaryn-code-releases/releases/latest)**.

| Device | File |
|---|---|
| Mac (Apple silicon) | `Velaryn-Code-<version>-arm64.dmg` |
| Windows 10/11 | `Velaryn-Code-Setup-<version>.exe` |
| Android | `Velaryn-Code-<version>.apk` |
| iPhone / iPad | `Velaryn-Code-<version>-unsigned.ipa` (install with Sideloadly or AltStore) |

The desktop apps update themselves from this page. Or use the website:
https://velaryn-soft.github.io/velaryn-code-web/
